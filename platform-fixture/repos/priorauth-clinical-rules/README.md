# priorauth-clinical-rules

Criteria evaluation for prior authorisation. Published as a jar and consumed by
`priorauth-api` and `priorauth-web`.

    com.meridiancare.clinical            criteria model and evaluation
    com.meridiancare.clinical.display    label formatting for consumers

Release process: bump the version in `pom.xml`, tag, publish. Consumers pick the
new version up when they choose to.
